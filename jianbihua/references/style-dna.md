# 风格 DNA

## 一句话

最终 IP 参考图 + 清爽手绘 Q 版，白底、留白、图解结构不说明书。

像一个元气打工人用可爱的手绘贴纸风在白纸上解释概念：画面清爽，角色认真干活，场景轻微荒诞。

## 必须

- 画幅按任务定：16:9 横版（默认）/ 3:4 竖版 / 贴图模式（白底单主体居中、四周大留白）。
- 纯白或透明背景：不要米色、暖灰、纸张纹理、渐变、阴影、噪点、复古纸感。
- 干净手绘线稿：线条圆润清楚，颜色柔和，不要写实厚涂。角色发色、粉色挑染、浅蓝 T 恤必须来自参考图。
- 大量留白：主体占画面约 40%-60%，至少 35% 空白。
- 少量中文手写批注：最多 5-8 处，每处 2-8 个字。
- 一张图只讲一个核心动作、结构、状态或隐喻。
- 图必须图解概念结构：谁给谁 / 流程 / 对比 / 状态变化。看完能复述结构才算合格，纯装饰贴纸不合格（贴图模式除外）。
- 结构自然表达，不在图上写结构类型名称。

## 颜色语义

- **黑/深棕**：主体线稿、头发暗部、普通标注。
- **粉色**：优先只用于角色发丝挑染和少量情绪小符号；不要把整张图染成粉色。
- **浅蓝**：角色默认 T 恤色，也可用于主强调词、主流程箭头、路径。
- **红色**：警示、坑、关键结果、情绪点、重点提醒。

蓝红只用于解释图的批注层，不必每张都齐，宁少不多。贴图模式默认角色完整上色 + 白底/透明底。

红蓝黑批注体系与封面手写字用色一致（蓝=主强调、红=次强调/热词、黑=结构），封面、插图、贴图视觉统一。

## 装饰规则

- 星星、爱心、汗滴、速度线等漫画情绪符号：贴图模式可少量点缀（≤3 处）；解释图里只在情绪确实是内容重点时用，否则不加。
- 装饰永远让位给结构表达，不铺满、不抢戏。

## 绝对不要

- 不要写实上色、厚涂、复杂光影。
- 不要商业插画、精致扁平插画、写实人像。
- 不要 PPT 信息图、课程课件。
- 不要正式流程图、复杂架构图。
- 不要过厚贴纸白边；普通干净白底或轻薄贴纸轮廓可以。
- 不要科技感 UI、真实 App 截图。
- 不要复杂背景、渐变、阴影、纹理。
- 不要把每个节点都解释清楚。
- 不要左上角写"流程图 / 系统架构图 / 常见坑 / 路线图"等类型标题。

## 审美方向

要清爽、元气、有点好笑、看得懂。

不要幼稚、复杂、死板、说明书感。

荒诞感的来源是打工场景本身的夸张——文件堆成山、进度条要用手拉、给 AI 机器一勺一勺喂材料——角色在荒诞场景里的反应是真实的。
