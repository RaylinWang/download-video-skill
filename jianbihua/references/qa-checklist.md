# QA Checklist

## 必过项

- 画幅正确（16:9 / 3:4 / 贴图模式）。
- 背景是干净白底。
- 角色与 `assets/character-ref.png` 一致：长深色头发 + 碎刘海、粉色挑染、大眼、浅蓝 T 恤。并排看一眼能认出是同一个人。
- 粉色主要在头发挑染上，不扩散成整张图主色。
- 颜色柔和干净，避免厚涂、复杂光影和大面积杂色。
- 角色承担核心动作，不只是装饰。
- 图解了概念结构（谁给谁 / 流程 / 对比 / 状态变化），看完能复述结构。贴图模式除外。
- 隐喻是为当前内容新发明的，没有复刻旧构图。
- 简洁清爽，主体不超过画面约 60%。
- 一张图只讲一个核心结构。
- 中文标注少、短、能读、没错字。
- 蓝色只用于主强调、主流向、路径。
- 红色只用于警示、坑、关键结果、情绪点。
- 装饰符号（星星/爱心/汗滴）：解释图基本不用；贴图模式 ≤3 处。

## 失败信号

出现以下情况，重生成或局部编辑：

- 角色跑模：发型变了、粉挂耳没了、眼型不对、加了眼镜（→ 上传参考图用"角色跑模"编辑提示重生）。
- 整图被上色、出现色块填充、渐变或阴影。
- 出现贴纸厚白边、贴纸包排版（一图多贴纸）。
- 粉色扩散到批注、箭头或物件。
- 角色淹没在物件里，一眼找不到主角（→ 用"角色不够跳"编辑提示重生）。
- 左上角出现"流程图 / 系统架构图 / 常见坑"等类型标题。
- 画面像 PPT、课程课件、正式流程图、商业插画。
- 元素太多、箭头太多、节点太多。
- 解释图变成纯装饰贴纸：图好看但讲不出结构。
- 背景有纸纹、阴影、渐变、米色、噪点。
- 中文错字严重或标注不可读。

## 迭代方法

- 太普通：让角色成为动作主体，加入一个奇怪但成立的打工隐喻。
- 太复杂：删节点，只保留一个动作和 3-5 个短标注。
- 角色跑模：必须上传参考图重生，不要只靠文字描述拉回来。
- 被写实/厚涂/贴纸化：强调 clean rounded hand-drawn chibi illustration、preserve the reference character、no heavy sticker border、no gradients。
- 太 PPT：去掉标题、边框、整齐网格和过多箭头，改成手绘场景。
- 文字错：优先局部编辑；错得多就重生成并减少标注数量。

## 交付判断

高质量图应该让读者先觉得"有点好笑"，然后 1 秒内看懂结构。

第一眼像教程页或像贴纸包，都不合格；要像一个元气打工人画在白纸上的解释漫画。
